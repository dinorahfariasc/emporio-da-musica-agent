# Agent instructions

This repository is worked on by AI coding agents (Claude Code, Codex, Cursor, …) at the user's
direction. Whatever agent you are:

1. Read `docs/HANDOFF.md` first — current status, environment, gotchas, working agreements.
2. Then read `CLAUDE.md` (project rules), `.specify/memory/constitution.md` (principles) and the
   newest entries of `docs/decision-log.md`.
3. Follow the rules in `CLAUDE.md` exactly, in particular: spec-driven workflow, English
   everywhere except the agent persona and website copy, semantic commits, **no AI/Claude
   mentions and no `Co-Authored-By` trailers in commits or PRs**, small PRs linked to issues,
   and the user merges.
4. Before ending a session, update `docs/HANDOFF.md` (status section) and append decisions to
   `docs/decision-log.md`.
